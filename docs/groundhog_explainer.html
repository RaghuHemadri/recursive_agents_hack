Groundhog

An agent team that doesn't relive the same day, in six steps.

Step 1 of 6 · every task Done Means Done

Solve one task

A lead writes down what "done" means before anyone starts. An analyst solves it, and a verifier re-derives the answer a different way. Nothing is submitted unless they agree.

If a guard trips (too many steps, a loop, the token budget), the team says "unsolved" instead of bluffing.

Step 2 of 6 · after every task Shared Brain

Learn from it

A reflector turns the task's trace into a lesson. One curator decides what enters the shared brain, and quarantines anything in the data that reads like an instruction.

Every agent reads BRAIN.md before its next task, so the 100th agent doesn't rediscover what the 1st learned.

Step 3 of 6 · every generation Version N+1

Rewrite how the team works

An improver reads the failed training traces and proposes a small edit to the team's own prompts, sub-agents, skills or routing, with a stated hypothesis.

The brain holds what the team knows. The harness holds how it works. This step changes the harness.

Step 4 of 6 · every generation Version N+1

Keep it only if it wins

Old and new versions run on the same tasks, which the improver has never seen. The new one is promoted only if it solves more, passes every security test and leaks nothing.

Rejected edits are archived with the reason, and the improver reads that archive next time.

Step 5 of 6 · always Guardrails

It can't move its own goalposts

Answers, the checker, the gate and the guardrails sit outside anything the improver can edit. When it reaches for them, it is denied and the attempt is logged.

Self-improvement erodes guardrails that live inside the agent. Ours live outside it.

Step 6 of 6 · the whole picture All together

Three loops, one team

Every task, the team solves and learns. Every generation, it rewrites itself and keeps the change only if it wins. Model weights never change.

Every model call runs on Nemotron through Crusoe Managed Inference.
