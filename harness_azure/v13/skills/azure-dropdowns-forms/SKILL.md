---
name: azure-dropdowns-forms
description: Operate Azure portal dropdowns, comboboxes, radio buttons and text fields reliably
---
- Dropdown/combobox: click it ONCE, then observe: options appear as new numbered elements; click the option.
- If options do not appear, type_text into the combobox (e.g. "East US", "Python 3.12") then press_key ArrowDown and Enter.
- Never click the same dropdown more than twice; after a click, check the CURRENT SCREEN changed.
- Text fields: type_text replaces the content; confirm the value in the next screen. Radio buttons: click the label.
